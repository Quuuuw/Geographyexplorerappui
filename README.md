# 地理探险家 🗺️

一个游戏化的地理学习Web应用，通过闯关答题和地图探索的方式，让学习地理知识变得有趣而高效。

## ✨ 主要功能

### 1. 🗺️ 地图探索
- 交互式中国地图，点击区域查看详情
- 显示每个地区的完成度和解锁状态
- 推荐任务系统，智能推荐下一步学习内容
- 实时搜索功能，快速定位目标地区

### 2. 🎯 闯关答题
- 游戏化的关卡地图，清晰展示学习进度
- 路径式节点设计，逐步解锁新内容
- 星级评分系统，激励用户追求更高成绩
- 统计数据展示，了解整体学习情况

### 3. ⚙️ 个性化筛选
- **地区选择**：中国/世界地图切换
- **学校阶段**：小学/初中/高中/通用
- **年龄范围**：6-9岁、10-12岁、13-15岁、16岁以上
- **难度等级**：5级难度设置
  - 🌱 入门（适合初学者）
  - 📚 基础（适合小学生）
  - 🎯 进阶（适合初中生）
  - 🚀 挑战（适合高中生）
  - 👑 专家（需要深厚知识）

### 4. 👤 个人中心
- 学习数据统计（总答题数、正确率、连续天数）
- 成就徽章系统，解锁不同成就
- 学习历史记录
- 每日挑战功能（NEW）

### 5. 📝 答题系统
**答题界面特色：**
- 题目展示（支持图文混合）
- 多选项卡片式设计（A/B/C/D）
- 实时倒计时功能
- 进度条显示

**答题反馈：**
- ✅ 答对：绿色高亮 + 积分奖励 + 详细解析
- ❌ 答错：红色标记错误选项 + 绿色显示正确答案 + 详细解析
- 📖 知识解析：每题都有详细的知识点讲解
- 💡 趣味小知识：增加学习趣味性

**结算页面：**
- 总得分和星级评价（⭐⭐⭐⭐⭐）
- 正确率统计
- 用时统计
- 详细答题记录
- 再来一局/返回地图/分享成绩功能

### 6. 🎯 每日挑战（附加功能）
- 每日更新的挑战任务
- 周进度追踪系统
- 丰厚的经验奖励
- 连续打卡激励

## 🎮 使用流程

1. **首次进入**：查看精美的欢迎动画
2. **探索地图**：在地图上点击感兴趣的地区
3. **开始挑战**：进入答题环节，选择答案
4. **查看反馈**：立即获得答案解析和知识补充
5. **完成结算**：查看成绩和详细统计
6. **持续学习**：解锁更多地区，完成每日挑战
7. **收集成就**：获得各种徽章，提升等级

## 🌟 亮点特色

1. **游戏化学习**：将地理知识学习变成有趣的游戏挑战
2. **个性化路径**：根据年龄和学校阶段定制学习内容
3. **即时反馈**：答题后立即获得详细解析
4. **进度可视化**：清晰的进度条和完成度展示
5. **成就系统**：激励用户持续学习
6. **精美动画**：流畅的过渡和反馈动画
7. **响应式设计**：适配各种设备尺寸
